# همراه درمان اعتیاد

اپلیکیشن آفلاین اندروید برای همراهی در سفر درمان اعتیاد، بر پایه مفاهیم **کنگره ۶۰**: کتاب **مسافر** و **راهنمای ویرایش ۹۹** (روش DST — تخفیف تدریجی مصرف تینکچر اپیوم بر حسب **سی‌سی**).

- 🟣 تم یاسی (بنفش) با فونت وزیرمتن
- ⭕🔺 آیکون و نماد رسمی کنگره ۶۰ (دایره و مثلث)

> ⚠️ **سلب مسئولیت:** این برنامه یک ابزار آموزشی و دفترچه یادداشت است و به‌هیچ‌وجه توصیه پزشکی نیست. مقدار مصرف و سرعت تخفیف را فقط راهنما یا پزشک تعیین می‌کند.

## 📲 گرفتن APK در ۴ قدم (بدون نیاز به Android Studio)

این پروژه یک **GitHub Actions workflow** آماده دارد که با هر Push، خودش APK را می‌سازد:

### قدم ۱ — آپلود در گیت‌هاب
1. وارد [github.com](https://github.com) شو و یک **Repository جدید** (Public یا Private) بساز.
2. کل محتویات این پوشه را در ریپو آپلود کن (فایل‌ها باید در **ریشه ریپو** باشند، نه داخل یک پوشه اضافه! یعنی `build.gradle.kts` مستقیم در ریشه دیده شود).

### قدم ۲ — اجرای خودکار بیلد
- بعد از آپلود، به تب **Actions** برو.
- ورک‌فلو «Build Android APK» خودکار اجرا می‌شود (حدود ۳ تا ۶ دقیقه).

### قدم ۳ — دانلود APK
- در تب Actions، روی بیلد تمام‌شده کلیک کن.
- در پایین صفحه بخش **Artifacts** دو فایل می‌بینی:
  - `Hamrah-release-APK` ← پیشنهادی (نسخه نهایی امضاشده)
  - `Hamrah-debug-APK` ← نسخه تست
- دانلود کن و زیپ آن را باز کن.

### قدم ۴ — نصب روی گوشی
1. فایل `apk` را به گوشی منتقل کن.
2. هنگام نصب، اجازه «نصب از منابع ناشناس» را بده (تنظیمات ← امنیت).
3. نصب کن و سفر را شروع کن ✋

> 💡 نسخه‌گذاری: هر بار که تگ `v1.0.0` مانند آن بسازی (`Releases → Draft a new release` یا `git tag v1.0.0 && git push origin v1.0.0`)، یک **GitHub Release** با APK ساخته می‌شود و لینک مستقیم دانلود می‌گیری.

## 🛠 بیلد محلی (اختیاری)

اگر Android Studio داری:
1. پروژه را باز کن (File → Open).
2. صبر کن تا Gradle Sync تمام شود.
3. از منوی Build گزینه **Build APK(s)** را بزن.

یا از ترمینال:
```bash
./gradlew assembleRelease
# خروجی: app/build/outputs/apk/release/app-release.apk
```
